# Photographer
Photographer web
demo: https://mixice.cn/

## Requirements

- PHP 7.4 or later
- MySQL 5.7+ / MariaDB 10.3+
- Apache or Nginx web server
- PHP extensions: mysqli, mbstring, gd, json, session

## Installation

1. Upload the contents of the `web/` directory to your web server's document root.
2. Make sure the `uploads/` directory is writable by the web server (`chmod 755 uploads/`).
3. Open `http://your-domain.com/install.php` in your browser.
4. Fill in the installation form:
   - **host** — MySQL server address (default: `localhost`)
   - **db name** — database name (will be created automatically)
   - **db user** — MySQL username
   - **db password** — MySQL password
   - **title** — your site title
   - **account** — admin login username
   - **password** — admin login password
5. Click **install**. The installer will import the database schema, write the database configuration to `db.php`, and create an `install.lock` file to prevent re-installation.
6. You will be redirected to the homepage. Access the admin panel at `http://your-domain.com/admin/`.

## Directory Structure

```
web/
├── admin/          Admin panel
├── includes/       Shared components (comment form, etc.)
├── images/         Static assets
├── styles/         CSS stylesheets
├── uploads/        User-uploaded files (must be writable)
├── db.php          Database configuration (auto-generated by installer)
├── install.php     One-time installer
├── database.sql    Database schema
└── *.php           Frontend pages
```
